プライバシーと注意事項

  • 選んだ動画は、インターネット上のサーバーには送られません。変換は、お使いの端末の中で行います。
  • 通信するのは、このページと変換プログラム（FFmpeg・約 31MB）を、このサイト（GitHub Pages）から読み込むときだけです。 2 回目以降は、ブラウザに保存された分が使われることがあります。
  • 外部のサーバー・CDN・アクセス解析・広告は使っていません。ページの設定（Content Security Policy）で、このサイト以外との通信をブラウザが止めるようにしています。
  • 動画の内容・ファイル名・映像や音声を、分析したり集めたりする機能はありません。
  • 選んだ表示言語だけは、次に開いたときのために、このブラウザの中に保存します。
  • 変換した動画には、撮影場所などのメタデータ（ファイルに付いている情報）を含めません。
  • このサイトは GitHub Pages で公開されているため、一般的な Web サイトと同じく、GitHub 社のサーバーにアクセス記録（IP アドレスなど）が残る場合があります。

大きな動画について

  • 変換には端末のメモリを使います。大きい・長い動画では、メモリが足りずに失敗したり、ブラウザが自動で再読み込みされたりすることがあります。
  • 目安はパソコンで 2GB まで、スマートフォンで 500MB 程度までです。失敗するときは、ほかのアプリやタブを閉じるか、「詳細設定」で解像度を下げるか、動画を短く切ってからお試しください。
  • 変換の速さは端末の性能しだいです。動画の長さの数倍の時間がかかることもあります。
