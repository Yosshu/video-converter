FFmpeg.wasm (@ffmpeg/ffmpeg __FFMPEG_VERSION__)

ブラウザの中で FFmpeg を動かすための JavaScript ライブラリです（Web Worker とのやり取りを担当）。

  • ライセンス：MIT License (Copyright (c) 2019 Jerome Wu)
  • 全文：licenses/ffmpeg.wasm-MIT.txt
  • ソースコード：github.com/ffmpegwasm/ffmpeg.wasm

@ffmpeg/core __CORE_VERSION__ (single-thread)

FFmpeg 5.1.4 を WebAssembly にしたもので、実際の変換はこれが行います（vendor/ffmpeg-core/ にそのまま置いています）。 GPL の機能を有効にしてビルドされ、GPL のライブラリ（x264・x265）を含むため、全体として GNU General Public License version 2 以降（GPL-2.0-or-later）で配布されています。

  • 全文：licenses/GPL-2.0.txt
  • ソースコードとビルド方法：github.com/ffmpegwasm/ffmpeg.wasm（Dockerfile と build/ に、使っている各ライブラリの取得元とバージョンがあります）
  • FFmpeg のソースコード：github.com/FFmpeg/FFmpeg (n5.1.4)
